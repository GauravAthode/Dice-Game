# 🎲 Dice Game – Two Player (First to 100 Wins)

A simple and interactive **Two-Player Dice Game** built using **HTML, CSS, Bootstrap, and JavaScript**.  
Players take turns rolling the dice, and the **first player to reach 100 points wins the game**.

---

## 🚀 Features

- 🎮 Two-player turn-based gameplay
- 🎯 Winning score set to **100**
- 🎲 Random dice roll (1–6)
- ✨ Dice spinning animation using CSS
- 🔊 Dice roll sound effect
- ▶️ Start Game & 🔄 Restart Game functionality
- 📱 Responsive UI with Bootstrap 5

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **JavaScript (Vanilla JS)**
